# Ruis

白黒基調のスタジオサイト(AI活用 × Web制作)。ビルド不要の静的サイトです。

## ファイル
- `index.html` … 中身(文章はここを書き換える)
- `style.css` … デザイン
- `script.js` … カーソルの動きなど
- `vercel.json` / `favicon.svg`

## GitHub と Vercel で公開する
1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべてアップロードする
2. https://vercel.com にGitHubでログインし「Add New → Project」でそのリポジトリを選ぶ
3. 設定はそのまま(Framework: Other)で「Deploy」を押す

## 公開前に書き換える所
- `index.html` の `hello@example.com` を自分のメールアドレスに
- 「つくったもの」のコンセプトサンプルを、実際の実績に
